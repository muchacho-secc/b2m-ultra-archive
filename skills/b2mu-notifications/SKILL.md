# B2MU — Notifications

## Purpose

The weekly summary notification answers one question before the athlete starts a new training week:
> "How did last week go, and what matters most this week?"

It is the only recurring notification. It is not a daily nudge, a streak reminder, or a motivational push — it is a concise, coach-like weekly debrief sent at a useful time.

---

## Notification types

| Type | Trigger | Priority |
|------|---------|----------|
| Weekly summary | Every Sunday evening (or Monday morning) | Phase 3 core |
| Missed long run alert | If long run not completed by Sunday 8pm | Phase 3 optional |
| Race week reminder | Monday of race week | Phase 3 optional |

Build the weekly summary first. The others are lower priority.

---

## Weekly summary — trigger and timing

**When:** Sunday at 8:00pm local time (AEDT/AEST)
**Condition:** Always send — even if it was a poor week. The summary is most valuable when things went wrong.
**Channel:** Telegram (same bot as VDGR, different message format)

```toml
# wrangler.toml
[triggers]
crons = ["0 9 * * 0"]   # 09:00 UTC Sunday = 19:00 AEST (UTC+10) — standard time (Apr–Oct)
                         # For daylight saving (Oct–Apr), use "0 8 * * 0" = 19:00 AEDT (UTC+11)
                         # Race week (late Oct) falls at the DST transition — verify cron timing
```

## Message content

The weekly summary message has four parts:

### 1. Week header
```
🏃 Week summary — Apr 13–19

Phase: BASE · Week 8 of 27 to race day
```

### 2. This week's numbers
```
✅ Sessions: 5/7 done
📏 Run km: 23km (target: 26km)
🏔 Long run: 18km ✓
```

### 3. AI coach commentary (2–3 sentences)
Generated by the Anthropic API. Specific, direct, coach-like.

Example (good week):
> "Solid week — 18km long run was the right call after two strong weeks at 16km. You're building well. Sunday's match on the same weekend as an 18km run shows your legs are adapting."

Example (missed session):
> "You missed Wednesday's gym session but kept the important stuff — the 18km long run and both easy runs. That's the right priority call. Don't try to make up the gym session this week."

Example (poor week):
> "Tough week — only 8km completed against a 26km target. One miss often leads to another. This week: just get the long run done. Everything else is secondary."

### 4. Next week preview
```
📅 Next week: Apr 20–26
Key session: Long Run Sunday — 20km (first 20km+ run)
Target: 28km total
```

## Generating the coach commentary

Called during the Sunday cron run:

```javascript
async function generateWeeklySummary(env, weekData) {
  const prompt = `
You are a direct ultra running coach. Write a 2-3 sentence weekly training summary.

Last week (${weekData.label}):
- Sessions completed: ${weekData.sessionsDone} of ${weekData.sessionsTotal} (excluding fixed football)
- Run km: ${weekData.actualKm}km of ${weekData.targetKm}km target
- Long run: ${weekData.longRunKm ? `${weekData.longRunKm}km ✓` : 'not completed'}
- Missed sessions: ${weekData.missedSessions.join(', ') || 'none'}
- Phase: ${weekData.phase}
- Weeks to race: ${weekData.weeksToRace}

Next week:
- Target km: ${weekData.nextWeekTargetKm}km
- Key session: ${weekData.nextWeekLongRun}km long run on Sunday
- Phase: ${weekData.nextWeekPhase}

Write 2-3 sentences. Be direct and specific. Reference actual km numbers. 
If it was a good week, acknowledge it briefly then focus forward.
If sessions were missed, name what happened and give one clear instruction for next week.
Do not use bullet points. Do not be generic. Sound like a coach who knows this athlete.
`;

  const res = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': env.ANTHROPIC_API_KEY,
      'anthropic-version': '2023-06-01'
    },
    body: JSON.stringify({
      model: 'claude-haiku-4-5-20251001', // Haiku is sufficient for short summaries — cheaper
      max_tokens: 150,
      messages: [{ role: 'user', content: prompt }]
    })
  });

  const data = await res.json();
  return data.content[0].text;
}
```

Use Haiku, not Sonnet — the output is short and structured. Sonnet is not needed and costs more.

## Telegram message builder

```javascript
function buildWeeklySummaryMessage(weekData, coachCommentary) {
  const sessionEmoji = weekData.sessionsDone >= weekData.sessionsTotal - 1 ? '✅' : '⚠️';
  const longRunEmoji = weekData.longRunKm ? '✅' : '❌';

  return `🏃 *Week summary — ${weekData.label}*
Phase: ${weekData.phase} · ${weekData.weeksToRace} weeks to race day

${sessionEmoji} Sessions: ${weekData.sessionsDone}/${weekData.sessionsTotal} done
📏 Run km: ${weekData.actualKm}km of ${weekData.targetKm}km target
🏔 Long run: ${weekData.longRunKm ? `${weekData.longRunKm}km ✓` : 'not completed'} ${longRunEmoji}

${coachCommentary}

📅 *Next week: ${weekData.nextWeekLabel}*
Key session: Long run ${weekData.nextWeekLongRun}km Sunday
Target: ${weekData.nextWeekTargetKm}km total`;
}

async function sendTelegramMessage(env, message) {
  await fetch(`https://api.telegram.org/bot${env.TELEGRAM_BOT_TOKEN}/sendMessage`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      chat_id: env.TELEGRAM_CHAT_ID,
      text: message,
      parse_mode: 'Markdown'
    })
  });
}
```

## Full cron handler

```javascript
export default {
  async scheduled(event, env, ctx) {
    const url = new URL(event.scheduledTime);
    // Sunday cron = weekly summary
    const dayOfWeek = new Date(event.scheduledTime).getUTCDay();
    if (dayOfWeek === 0) {
      ctx.waitUntil(runWeeklySummary(env));
    }
  }
};

async function runWeeklySummary(env) {
  try {
    const weekData = await buildWeekData(env);
    const commentary = await generateWeeklySummary(env, weekData);
    const message = buildWeeklySummaryMessage(weekData, commentary);
    await sendTelegramMessage(env, message);
    console.log('Weekly summary sent successfully');
  } catch (err) {
    console.error('Weekly summary failed:', err);
    // Send a fallback plain message rather than silence
    await sendTelegramMessage(env,
      `🏃 Weekly training summary could not be generated. Check the app for your week overview.`
    );
  }
}
```

## Assembling week data from Supabase

```javascript
async function buildWeekData(env) {
  const today = new Date();
  const weekStart = getLastMonday(today); // YYYY-MM-DD

  // Fetch this week's sessions
  const sessions = await getWeekSessions(env, weekStart);

  // Exclude fixed football sessions from done/total counts
  const trainingSessions = sessions.filter(s => !s.isFixed);
  const sessionsDone = trainingSessions.filter(s => s.status === 'completed').length;
  const sessionsTotal = trainingSessions.length;

  // Long run
  const longRun = sessions.find(s => s.subtype === 'Long Run' && s.status === 'completed');

  // Missed sessions (non-fixed, non-rest)
  const missed = trainingSessions
    .filter(s => s.status === 'missed' && s.type !== 'rest')
    .map(s => `${s.day} ${s.subtype}`);

  // Next week
  const nextWeekStart = addDays(weekStart, 7);
  const nextWeekSessions = await getWeekSessions(env, nextWeekStart);
  const nextLongRun = nextWeekSessions.find(s => s.subtype === 'Long Run');

  return {
    label: formatWeekLabel(weekStart),
    phase: await getCurrentPhase(env),
    weeksToRace: weeksUntilRace(today),
    actualKm: sessions.filter(s => s.type === 'run' && s.status === 'completed')
                      .reduce((sum, s) => sum + s.distanceKm, 0),
    targetKm: await getWeekTargetKm(env, weekStart),
    longRunKm: longRun?.distanceKm || null,
    sessionsDone,
    sessionsTotal,
    missedSessions: missed,
    nextWeekLabel: formatWeekLabel(nextWeekStart),
    nextWeekLongRun: nextLongRun?.distanceKm || null,
    nextWeekTargetKm: await getWeekTargetKm(env, nextWeekStart),
    nextWeekPhase: await getPhaseForWeek(env, nextWeekStart),
  };
}
```

## Optional: missed long run alert

If Sunday passes and the long run has not been completed:

```javascript
// Fires Sunday at 8pm if long run not done
async function checkMissedLongRun(env) {
  const today = new Date().toISOString().split('T')[0];
  const longRunSession = await getLongRunSession(env, today);

  if (longRunSession && longRunSession.status === 'planned') {
    await sendTelegramMessage(env,
      `⚠️ Long run not yet marked complete. Did you get it done? Log it in the app so your coach has accurate data.`
    );
  }
}
```

Only send this if the long run was planned for Sunday. Do not send if it was already moved to another day.

## Rules for good notifications

**Send:**
- Weekly summary — always, regardless of how the week went
- Race week reminder — Monday of race week only

**Do not send:**
- Daily training reminders — the app is not a habit tracker
- Streak notifications — not relevant to ultra training
- "You haven't opened the app" prompts — invasive and not useful
- Mid-week check-ins — the weekly cadence is sufficient
- Motivational quotes — not coach-like

**Tone rules:**
- Always specific — reference actual km numbers, session names, dates
- Never generic — "great week!" is not acceptable without specifics
- Honest about poor weeks — the coach doesn't sugarcoat a bad week
- Forward-looking — always end with what matters next week
- Brief — the message should be readable in 15 seconds

## Rules
- Use Haiku for weekly summary generation — Sonnet is not needed for short structured output
- Always send a fallback message if generation fails — silence is worse than a simple message
- Never send more than one notification type per day
- Cron runs at 09:00 UTC = 19:00 AEST (standard time, Apr–Oct); switch to 08:00 UTC during AEDT (daylight saving, Oct–Apr)
- Exclude fixed football sessions from done/total session counts in the summary
- The coach commentary must reference actual numbers — never generate generic text
